# Canada West Position Action Exposure webpage

This is a static HTML website. It does not require R to run.

## Preview locally
Open `index.html` in a web browser. Keep the `assets` folder beside it.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `canada-west-action-exposure`).
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub to publish the site. The Pages URL will appear in that section.

## Update the content
Edit `index.html`. If replacing a chart, keep the same image filename in `assets` or update the corresponding image path in the HTML.

## Method note
The page deliberately calls these values **coded actions per team set**, not verified physical jumps. The DVW action codes do not establish whether every attack or block involved a jump, whether a set was a jump set, or how many blockers jumped on a play.
